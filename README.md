# SoundTracker — 纯本地伴奏提取 · 移调变速 · 音量放大 · 多轨混剪工坊 (Android)

**SoundTracker** 是一款 **100% 纯客户端离线运行** 的 Android 音频处理与多轨剪辑应用。无需任何后端服务器或联网上传，在手机本地即可完成网易云 `.ncm` 无损导入、AI 人声伴奏分离、边听边调移调变速、防破音音量放大、多轨切片混剪（最多 10 轨），以及一键微信分享与存储空间精细管理。

## 核心功能与技术架构

### 1. 网易云音乐 (`.ncm`) 无损导入与本地音视频解码
- **网易云音乐直连扫描 (`NetEaseCloudMusicManager`)**：自动扫描手机本地网易云下载目录，支持搜索与多选批量导入；在端侧通过 AES-128 元数据解包与 RC4 流还原直接提取内嵌原生 **FLAC / MP3** 音频流，零二次有损重编码。
- **全格式本地导入**：支持从系统文件选择器导入手机中的 `MP3 / FLAC / M4A / WAV / MP4` 等常见音频与视频文件。

### 2. 双模型 AI 去人声提取伴奏 (`UVR-MDX-NET Inst-HQ5` + `Meta HTDemucs-FT v4`)
- **人声去除优先 (`UVR-MDX-NET Inst_HQ_5`)**：全频段（直达 `22.05 kHz`）直接预测纯伴奏频谱，彻底压制主唱、和声、气声与混响尾音，可选开启二次深度消噪。
- **乐器音质优先 (`Meta HTDemucs-FT v4`)**：时域波形 + 频域频谱双分支混合 Transformer 模型，完整保留鼓点、贝斯与原声乐器的饱满瞬态。
- **双模型均衡模式 (`Ensemble Crossover Fusion`)**：融合两种模型优势，兼顾干净的人声剥离度与自然的乐器质感。
- 支持可选同步输出清唱人声轨，以及一键 **A/B 对比原曲** 无缝切换试听。

### 3. 自动 BPM 测速 + 移调与 1 BPM 变速（「边听边调」实时预览）
- **自动 BPM 识别**：C++ 20 频带对数谱通量瞬态包络提取 + 多周期脉冲梳状自相关，导入音乐时自动测算原曲 BPM，并支持手动校准原曲基准速度。
- **边听边调实时试听 (`RubberBandRealtimeProcessor`)**：接入 Media3 `ExoPlayer` 自定义音频管线，播放时拖动滑杆或连点 `− / +` 即可零等待听到 **1 BPM 精度变速** 与 **半音升降调** 效果（可选保持人声音色）。
- **高保真离线生成 (`Rubber Band v4.0 R3 Finer`)**：确认参数后由多分辨率 STFT 双趟离线引擎单遍合成新音轨，消除移调电音感。

### 4. 母带级防破音音量放大（「边听边调」实时预览）
- 实时分析 **ITU-R BS.1770-4 综合响度 (`LUFS`)** 与 **4x 超采样真峰值 (`dBTP`)**。
- **实时试听与离线同源引擎 (`RealtimeVolumeMaximizer` / `boostVolumeTransparent`)**：支持 `0 ~ +18 dB` 边播边调实时试听；在 `-0.2 dBTP` 余量内执行 100% 线性无损等比放大，超出余量时自动启用 **5ms 前瞻立体声联动真峰值防破音限幅器**，避免硬削波爆音。

### 5. 编曲级多轨切片与混剪工作台（`多轨剪辑`，支持 1~10 轨）
- **双工作台架构**：底部常驻 **`单曲处理`** 与 **`多轨剪辑`** 双模式切换；单曲卡片与列表支持一键 **`送去剪辑`**。
- **1~10 条弹性多轨**：默认提供 1 条音轨（`音轨 1`），点击轨道下方 **`+`** 可按需扩展至最多 **10 条音轨**；每条音轨左侧固定轨道头独立支持 **静音、独奏、单轨音量调节（`-18 ~ +12 dB`）** 与删除轨道。
- **任意切片与手势编排**：
  - 支持整首上轨或预选时间区间切片上轨（同一首音乐可多次截取不同段落拼贴），也可在剪辑台内直接从网易云或本地导入新歌上轨。
  - 中心固定播放指针，支持单指左右惯性滑动定位、双指捏合无级缩放时间轴（`6 ~ 120 dp/s`）、单指上下浏览多轨。
  - 支持在指针处一键分割、拖拽片段左右粗把手实时裁剪起止点、按住片段跨轨移动与磁吸对齐（自动吸附 `00:00`、播放指针及其他片段首尾边缘）。
  - 底部恒定高度控制坞提供 `±0.1s` 位置/起点/终点微调、`贴前段`、`至指针`、单段独立音量、淡入/淡出/首尾淡化、复制、上下移轨（末轨下移自动新建音轨）以及 `30` 步撤销/重做。
- **C++ 采样级混音与合成 (`RealtimeMultiTrackEngine`)**：底层采用 POSIX `pread` 无锁随机读取直推单路低延迟 `AudioTrack`，保障多轨叠加零相位漂移与平滑防爆音切口；点击 **`合成新音轨`** 离线混音并执行 `-0.2 dBTP` 真峰值防破音保护，自动回流至单曲工作台。

### 6. 重命名、微信直享与可视化存储资源管理
- **多格式导出与分享**：支持 **MP3 (320kbps LAME)**、**M4A (256kbps AAC)** 与 **WAV (16-bit TPDF 抖动无损)**，支持自由重命名、一键分享至微信好友/文件传输助手，或另存到手机 `Music/SoundTracker` 及任意自定义目录。
- **可视化存储资源管理**：点击顶部「扫把 + 占用体积」胶囊可查看工作台音轨与临时缓存明细，支持单条清理、多选批量删除与一键全清。
- **零高度跳变暖色纸感 UI**：采用暖羊皮纸与赤陶色（Warm Parchment & Terracotta）设计体系，所有实时开关与底部控制坞均锁定恒定高度，连点微调按钮不移位。

## 编译与安装

```bash
export JAVA_HOME="$PWD/.tools/jdk"
export ANDROID_HOME="$HOME/Library/Android/sdk"

./gradlew assembleRelease && cp -f app/build/outputs/apk/release/app-release.apk build/SoundTracker.apk
adb install -r build/SoundTracker.apk
```
